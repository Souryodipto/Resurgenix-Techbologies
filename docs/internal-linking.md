# Internal Linking Architecture & Topical Mesh

This document maps the contextual linking network across the Resurgenix website. Every page has minimum inbound and outbound requirements to ensure zero orphan pages, seamless user progression, and search engine topical authority.

---

## 1. Internal Linking Governance Rules

1. **Zero Orphan Pages:** Every page must receive at least 2 internal contextual in-body links (beyond header and footer navigation).
2. **Contextual Anchor Text:** Never use generic "Click Here" or "Read More". Use descriptive keyword-rich anchors (e.g. _"explore restricted zone detection capabilities"_, _"review our on-premise deployment architecture"_).
3. **Cross-Silo Linking Mesh:**
   - **Solution Pages** must link to relevant **Industry Pages** and supporting **Technical Articles**.
   - **Industry Pages** must link to primary **Solution Capabilities** and relevant **Pilot/Demo flows**.
   - **Articles & Resources** must bridge informational search queries to **Solution Capabilities** and the **Pilot Evaluation Form**.
   - **Regional Page** (`/locations/kolkata-eastern-india`) must link to local pilot requests and enterprise industry solutions.
